# GitHub Actions

[![CI](https://github.com/AlinaPavlenk18/github-actions/actions/workflows/ci.yml/badge.svg)](https://github.com/AlinaPavlenk18/github-actions/actions/workflows/ci.yml)

A small text-utilities module used as a learning project for practicing GitHub Actions.

Includes functions to check palindromes, count words, and reverse word order in a string.

## Scripts
- `npm run build` — copies source files into `dist/`
- `npm test` — runs the test suite
